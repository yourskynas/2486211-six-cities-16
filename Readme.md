# Шесть городов

**Шесть городов** — это сервис для путешественников, которые ищут доступное жилье в популярных городах Европы. Приложение позволяет выбирать предложения по аренде, фильтровать и сортировать их, просматривать подробную информацию о жилье, добавлять объекты в избранное, а также видеть их местоположение на карте. Лаконичный интерфейс помогает сосредоточиться на поиске идеального варианта.

---

## Функциональные возможности

### 1. Страницы приложения

#### Главная страница (`/`)
- Отображает список доступных городов: Paris, Cologne, Brussels, Amsterdam, Hamburg, Dusseldorf.
- При выборе города загружаются предложения по аренде для него.
- Предложения отображаются в виде списка и на карте:
  - Сортировка предложений:
    - `Popular` (по умолчанию).
    - `Price: low to high` (от дешёвых к дорогим).
    - `Price: high to low` (от дорогих к дешёвым).
    - `Top rated first` (по рейтингу).
  - Карточка предложения содержит:
    - Изображение, цену, описание, тип жилья, рейтинг, статус премиальности и кнопку "Избранное".
  - Наведение на карточку подсвечивает маркер на карте.
- Если предложений нет, выводится сообщение: "No places to stay available" и статичное изображение вместо карты.

#### Страница предложения (`/offer/:id`)
- Содержит подробную информацию об объекте:
  - Фотографии, заголовок, описание, рейтинг, количество спален, вместимость, стоимость за ночь, удобства.
  - Информация о владельце: аватарка, имя, отметка "Pro".
  - Список отзывов пользователей (до 10 отзывов, сортировка от новых к старым).
  - Для авторизованных пользователей доступна форма отправки отзыва.
- На карте отображается текущий объект и 3 ближайших предложения.
- Под картой отображается список ближайших предложений.

#### Страница избранного (`/favorites`)
- Приватная страница, доступная только авторизованным пользователям.
- Отображает предложения, добавленные в избранное, сгруппированные по городам.
- Количество избранных предложений отображается рядом с email пользователя.

#### Страница логина (`/login`)
- Позволяет авторизоваться в приложении, указав email и пароль:
  - Пароль должен содержать хотя бы одну букву и одну цифру.
  - Авторизованные пользователи перенаправляются на главную страницу.

#### Страница 404
- Пользователь перенаправляется на страницу с сообщением об ошибке, если введён некорректный URL.

### 2. Взаимодействие с сервером
- Все данные загружаются и сохраняются на сервере:  
  https://16.design.htmlacademy.pro/six-cities.
- Сервер работает с JSON-данными.
- Для авторизации используется токен, который сохраняется в localStorage под именем six-cities-token и передаётся в заголовке X-Token при каждом запросе.

---

### 3. Обратная связь интерфейса
- Кнопки изменяют состояние при выполнении действий:
  - "Submit" → "Submitting...", "Add to favorites" → "Adding...".
- В случае ошибки уведомление отображается в виде визуального эффекта.

## Технологии
- **React** — построение пользовательского интерфейса.
- **Redux Toolkit** — управление состоянием приложения.
- **React Router** — маршрутизация.
- **Axios** — взаимодействие с сервером.
- **Leaflet** — отображение карт.
- **OpenAPI** — спецификация взаимодействия с сервером.
